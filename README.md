# NIKIFOROV MERCH

Одностраничный каталог мерча колледжа NIKIFOROV. Сейчас в нём представлены девять цветовых вариантов рюкзака; структура позволяет добавлять новые категории и товары.

## Возможности

- Адаптивная витрина и каталог рюкзаков.
- Подробный просмотр товара и выбор количества.
- Корзина-заявка с сохранением выбранных товаров в браузере.
- Подготовка текста заявки с именем, телефоном или Telegram и комментарием.
- Копирование/передача заявки менеджеру. Стоимость, наличие, доставка и оплата согласовываются с менеджером.

**Важно:** автоматическая отправка заказа и онлайн-оплата не подключены. Для прямой передачи заявок нужно согласовать контакт или канал менеджера.

## Запуск

Сайт статический, сборка и зависимости не требуются. Из корня проекта:

```bash
python3 -m http.server 8080 --directory dist
```

Затем открыть `http://localhost:8080`.

## Структура

- `dist/index.html` — разметка страницы.
- `dist/styles.css` — оформление и адаптивная вёрстка.
- `dist/main.js` — каталог, карточки и логика заявки. Новые товары добавляются в массив `products`.
- `dist/assets/` — фотографии для сайта.
- `scripts/` — вспомогательные скрипты и индекс исходной фотогалереи.
